# Arlen归物小程序

一个使用微信原生小程序技术实现的个人物品成本管理工具。数据只保存在用户本机，不依赖服务器或云开发。

## 本地运行

1. 下载并打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择 `D:\codex\wupin-billing-miniapp`。
4. AppID 选择测试号（或换成你自己的小程序 AppID）。
5. 导入后点击“编译”。

## 计费规则

日均成本 =（购入价格 - 预计残值）÷ 预计使用天数。

累计成本从购入日期开始计算，达到预计使用寿命后停止增长；暂停计费期间不累计成本。记录使用次数后，还会计算单次使用成本。

## 功能

- 新增、编辑、删除物品
- 分类、搜索和排序
- 自动计算日均成本、累计成本和当前估值
- 使用次数打卡与单次使用成本
- 暂停和恢复计费
- 分类金额、未来成本和每日成本排行
- 微信本地持久化存储

## 发布给自己和朋友使用

当前 `project.config.json` 已配置正式 AppID `wx0892fe2f87d13e75`，可以使用有该小程序开发权限的微信账号上传版本。

### 体验版

1. 在微信公众平台添加开发者与体验成员。
2. 使用该小程序的管理员或开发者微信登录开发者工具。
3. 点击开发者工具右上角“上传”，版本号填写 `1.0.0`。
4. 登录微信公众平台，在“版本管理”中把开发版本设为体验版。
5. 体验成员扫码即可使用。

### 正式版

1. 在微信公众平台填写昵称“Arlen归物”、头像、简介和服务类目。
2. 按平台提示完成小程序备案与隐私保护指引。
3. 上传 `1.0.0` 代码并先用体验版完成真机测试。
4. 在“版本管理”中提交审核，功能页面选择 `pages/home/home`。
5. 审核通过后点击“发布”，即可供朋友扫码、转发或搜索使用。
